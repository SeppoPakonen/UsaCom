### M8-4: Computing Book Value (Straight-Line Depreciation)

Calculate the book value of a three-year-old machine that has:
- Cost: $31,000
- Estimated residual value: $1,000
- Estimated useful life: 5 years
- Method: Straight-line depreciation

**Solution:**
```
Annual depreciation = ($31,000 - $1,000) / 5 = $6,000
Accumulated depreciation after 3 years = $6,000 × 3 = $18,000
Book value = $31,000 - $18,000 = $13,000
```

### M8-5: Computing Book Value (Double-Declining-Balance Depreciation)

Calculate the book value of a three-year-old machine that has:
- Cost: $55,000
- Estimated residual value: $5,000
- Estimated useful life: 5 years
- Method: Double-declining-balance depreciation

**Solution:**
```
DDB rate = (1/5) × 2 = 40%
Year 1: $55,000 × 40% = $22,000; Book value = $33,000
Year 2: $33,000 × 40% = $13,200; Book value = $19,800
Year 3: $19,800 × 40% = $7,920; Book value = $11,880
```

### M8-6: Computing Book Value (Units-of-Production Depreciation)

Calculate the book value of a three-year-old machine that has:
- Cost: $26,000
- Estimated residual value: $1,000
- Estimated useful life: 50,000 machine hours
- Method: Units-of-production depreciation
- Actual usage: Year 1: 3,200 hours; Year 2: 7,050 hours; Year 3: 7,500 hours

**Solution:**
```
Depreciation rate = ($26,000 - $1,000) / 50,000 = $0.50 per hour
Total hours used = 3,200 + 7,050 + 7,500 = 17,750 hours
Accumulated depreciation = 17,750 × $0.50 = $8,875
Book value = $26,000 - $8,875 = $17,125
```

### M8-8: Recording the Disposal of a Long-Lived Asset

Bonham's Bakery sold shelving units (store fixtures) that were 10 years old for $1,800 cash. Original cost was $6,500, depreciated on a straight-line basis over 12 years with an estimated residual value of $800.

**Required:** Record the sale of the shelving units.

**Solution:**
```
Annual depreciation = ($6,500 - $800) / 12 = $475
Accumulated depreciation after 10 years = $475 × 10 = $4,750
Book value = $6,500 - $4,750 = $1,750
Gain on sale = $1,800 - $1,750 = $50

Journal Entry:
  Cash                    1,800
  Accumulated Depreciation 4,750
    Store Fixtures                    6,500
    Gain on Sale of Assets              50
```

### M8-9: Computing Goodwill and Patents

Elizabeth Pie Company has been in business for 50 years. Giant Bakery Inc. has made an offer to buy Elizabeth Pie Company for $5,000,000.

**Facts:**
- Book value of Elizabeth Pie's recorded assets and liabilities: $4,300,000
- Fair value of recorded assets and liabilities: $4,500,000
- Patent (developed internally, never recorded): Fair value $300,000
- Goodwill from loyal customers (never recorded): Estimated $310,000

**Required:** Should Elizabeth Pie Company management accept Giant Bakery's offer? Compute the amount of goodwill that Giant Bakery should record.

**Solution:**
```
Fair value of net identifiable assets:
  Recorded assets (fair value)    $4,500,000
  Patent (fair value)                300,000
  Total fair value                 $4,800,000

Goodwill = Purchase price - Fair value of net identifiable assets
Goodwill = $5,000,000 - $4,800,000 = $200,000

Recommendation: The offer of $5,000,000 exceeds the fair value of net identifiable assets
($4,800,000) by $200,000. Management should consider whether this premium is reasonable
given the company's internally generated goodwill and future earning potential.
```

### E8-4: Determining Financial Statement Effects of an Asset Acquisition and Depreciation

During Year 1, Ashkar Company ordered a machine on January 1 at an invoice price of $21,000. On January 2, paid $6,000 on the machine, with the balance on credit at 10% interest due in six months. On January 3, paid $1,000 for freight. On January 5, paid installation costs of $2,500. On July 1, paid the balance due plus interest. Depreciation recorded using straight-line method (10-year life, $4,000 residual value).

**Required:**

1. Indicate the effects of each transaction on the accounting equation.
2. Compute the acquisition cost of the machine.
3. Compute the depreciation expense for Year 1.
4. What impact does the interest paid have on the cost of the machine?
5. What would be the net book value at the end of Year 2?

**Solution:**

1. **Accounting Equation Effects:**

| Date | Assets | = | Liabilities | + | Stockholders' Equity |
|------|--------|---|-------------|---|---------------------|
| Jan 1 | No effect | | No effect | | No effect |
| Jan 2 | +Machine $6,000, -Cash $6,000 | | +Note Payable $15,000 | | No effect |
| Jan 3 | +Machine $1,000, -Cash $1,000 | | No effect | | No effect |
| Jan 5 | +Machine $2,500, -Cash $2,500 | | No effect | | No effect |
| Jul 1 | -Cash $16,500 | | -Note Payable $15,000, -Interest Payable $750 | | -Interest Expense $750 |

2. **Acquisition Cost:**
```
Invoice price          $21,000
Freight                  1,000
Installation             2,500
Total Acquisition Cost $24,500
```

3. **Depreciation Expense Year 1:**
```
($24,500 - $4,000) / 10 = $2,050
```

4. **Interest Impact:** Interest expense ($750) is NOT included in the asset cost. It is expensed in the period incurred. Interest can only be capitalized during construction of assets for a company's own use.

5. **Net Book Value End of Year 2:**
```
Year 1 depreciation: $2,050
Year 2 depreciation: $2,050
Accumulated depreciation: $4,100
Net book value: $24,500 - $4,100 = $20,400
```

### E8-9: Computing Depreciation under Alternative Methods

Purity Ice Cream Company bought a new ice cream maker at the beginning of the year:
- Cost: $9,000
- Estimated useful life: 4 years
- Residual value: $1,000
- Estimated productive life: 16,000 hours
- Actual usage: Year 1: 5,500 hrs; Year 2: 3,800 hrs; Year 3: 3,200 hrs; Year 4: 3,500 hrs

**Required:** Complete a separate depreciation schedule for each method.

**Solution:**

**a. Straight-Line Method:**

| Year | Computation | Depreciation Expense | Accumulated Depreciation | Net Book Value |
|------|-------------|---------------------|-------------------------|----------------|
| At acquisition | | | | $9,000 |
| 1 | ($9,000-$1,000)/4 | $2,000 | $2,000 | 7,000 |
| 2 | ($9,000-$1,000)/4 | 2,000 | 4,000 | 5,000 |
| 3 | ($9,000-$1,000)/4 | 2,000 | 6,000 | 3,000 |
| 4 | ($9,000-$1,000)/4 | 2,000 | 8,000 | 1,000 |

**b. Units-of-Production Method:**

Depreciation rate = ($9,000 - $1,000) / 16,000 = $0.50 per hour

| Year | Computation | Depreciation Expense | Accumulated Depreciation | Net Book Value |
|------|-------------|---------------------|-------------------------|----------------|
| At acquisition | | | | $9,000 |
| 1 | $0.50 × 5,500 | $2,750 | $2,750 | 6,250 |
| 2 | $0.50 × 3,800 | 1,900 | 4,650 | 4,350 |
| 3 | $0.50 × 3,200 | 1,600 | 6,250 | 2,750 |
| 4 | $0.50 × 3,500* | 1,750 | 8,000 | 1,000 |

*Note: Year 4 is limited to bring book value to residual value.

**c. Double-Declining-Balance Method:**

DDB rate = (1/4) × 2 = 50%

| Year | Computation | Depreciation Expense | Accumulated Depreciation | Net Book Value |
