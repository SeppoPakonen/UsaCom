## AP8-3: Computing the Acquisition Cost and Recording Depreciation under Three Alternative Methods

At the beginning of the year, Plummer's Sports Center bought three used fitness machines from Advantage, Inc. The machines immediately were overhauled, installed, and started operating.

**Costs:**

| | Machine A | Machine B | Machine C |
|---|-----------|-----------|-----------|
| Amount paid for asset | $11,000 | $30,000 | $8,000 |
| Installation costs | 500 | 1,000 | 500 |
| Renovation costs prior to use | 2,500 | 1,000 | 1,500 |

By the end of the first year, each machine had been operating 4,800 hours.

**Required:**

1. Compute the cost of each machine.

2. Give the entry to record depreciation expense at the end of Year 1, assuming:

| Machine | Life | Residual Value | Depreciation Method |
|---------|------|----------------|---------------------|
| A | 5 years | $1,000 | Straight-line |
| B | 60,000 hours | 2,000 | Units-of-production |
| C | 4 years | 1,500 | Double-declining-balance |

**Solution:**

1. **Cost of Each Machine:**

| | Machine A | Machine B | Machine C |
|---|-----------|-----------|-----------|
| Purchase price | $11,000 | $30,000 | $8,000 |
| Installation | 500 | 1,000 | 500 |
| Renovation | 2,500 | 1,000 | 1,500 |
| **Total Cost** | **$14,000** | **$31,500** | **$10,000** |

2. **Depreciation Expense - Year 1:**

**Machine A (Straight-line):**
```
($14,000 - $1,000) / 5 = $2,600
```

**Machine B (Units-of-production):**
```
Rate = ($31,500 - $2,000) / 60,000 = $0.4917 per hour
Depreciation = $0.4917 × 4,800 = $2,360
```

**Machine C (Double-declining-balance):**
```
DDB rate = (1/4) × 2 = 50%
Depreciation = $10,000 × 50% = $5,000
```

**Journal Entry:**
```
  Depreciation Expense - Machine A     2,600
  Depreciation Expense - Machine B     2,360
  Depreciation Expense - Machine C     5,000
    Accumulated Depreciation - Machine A      2,600
    Accumulated Depreciation - Machine B      2,360
    Accumulated Depreciation - Machine C      5,000
```

## AP8-4: Inferring Depreciation Amounts and Determining the Effects of a Depreciation Error on Key Ratios

Best Buy Co., Inc. reported the following (in millions):

**CONSOLIDATED BALANCE SHEETS**

| | Current Year | Prior Year |
|---|------------|------------|
| **Property and Equipment:** | | |
| Land and buildings | $766 | |
| Leasehold improvements | 2,318 | |
| Fixtures and equipment | 4,701 | |
| Property under capital lease | 120 | |
| **Total** | **7,905** | |
| Less accumulated depreciation | 4,082 | |
| **Net property and equipment** | **$3,823** | |

**Required:**

1. Assuming that Best Buy did not sell any property, plant, and equipment in the current year, what was the amount of depreciation expense recorded during the current year?

2. Assume that Best Buy failed to record depreciation during the current year. Indicate the effect of the error on:
   - a. Earnings per share
   - b. Fixed asset turnover
   - c. Current ratio

## P8-5: Evaluating the Effect of Alternative Depreciation Methods on Key Ratios from an Analyst's Perspective

You are a financial analyst for Ford Motor Company. A machine cost $106,000. Estimated useful life is 13 years, estimated residual value is $2,000. Estimated useful life in productive output is 200,000 units. Actual output: Year 1: 20,000 units; Year 2: 16,000 units.

**Required:**

1. For Years 1 and 2 only, prepare separate depreciation schedules assuming:
   - a. Straight-line method
   - b. Units-of-production method
   - c. Double-declining-balance method

2. Evaluate each method in terms of its effect on cash flow, fixed asset turnover, and EPS.

**Solution:**

**a. Straight-Line Method:**

| Year | Computation | Depreciation Expense | Accumulated Depreciation | Net Book Value |
|------|-------------|---------------------|-------------------------|----------------|
| At acquisition | | | | $106,000 |
| 1 | ($106,000-$2,000)/13 | $8,000 | $8,000 | 98,000 |
| 2 | ($106,000-$2,000)/13 | 8,000 | 16,000 | 90,000 |

**b. Units-of-Production Method:**

Rate = ($106,000 - $2,000) / 200,000 = $0.52 per unit

| Year | Computation | Depreciation Expense | Accumulated Depreciation | Net Book Value |
|------|-------------|---------------------|-------------------------|----------------|
| At acquisition | | | | $106,000 |
| 1 | $0.52 × 20,000 | $10,400 | $10,400 | 95,600 |
| 2 | $0.52 × 16,000 | 8,320 | 18,720 | 87,280 |

**c. Double-Declining-Balance Method:**

DDB rate = (1/13) × 2 = 15.38%

| Year | Computation | Depreciation Expense | Accumulated Depreciation | Net Book Value |
|------|-------------|---------------------|-------------------------|----------------|
| At acquisition | | | | $106,000 |
| 1 | $106,000 × 15.38% | $16,303 | $16,303 | 89,697 |
| 2 | $89,697 × 15.38% | 13,795 | 30,098 | 75,902 |

**2. Evaluation:**

| Method | Cash Flow | Fixed Asset Turnover | EPS (Year 1) |
|--------|-----------|---------------------|--------------|
| Straight-line | No effect (non-cash) | Moderate | Moderate |
| Units-of-production | No effect (non-cash) | Varies with production | Varies |
| DDB | No effect (non-cash) | Higher (lower assets) | Lower (higher expense) |

**Recommendation:** If Ford is most interested in reducing taxes and maintaining high EPS for Year 1, I would recommend **straight-line** for financial reporting (higher EPS) while using an accelerated method for tax purposes if allowed.

## P8-6: Recording and Interpreting the Disposal of Three Long-Lived Assets

Merkley Company disposed of three assets during the current year. On January 1:

| Asset | Original Cost | Residual Value | Estimated Life | Accumulated Depreciation |
|-------|--------------|----------------|----------------|-------------------------|
| Machine A | $21,000 | $3,000 | 8 years | $15,750 (7 years) |
| Machine B | $50,000 | $4,000 | 10 years | $36,800 (8 years) |
| Machine C | $85,000 | $5,000 | 15 years | $64,000 (12 years) |

**Disposals:**
- a. Machine A: Sold on January 1 for $5,000 cash
- b. Machine B: Sold on December 31 for $10,500; received $2,500 cash and an $8,000 note receivable
- c. Machine C: Suffered irreparable damage on January 1; removed by salvage company at no cost on January 10

**Required:**

1. Give all journal entries related to the disposal of each machine.
2. Explain the accounting rationale for each disposal.

**Solution:**

**a. Machine A Disposal (January 1):**
```
Book value = $21,000 - $15,750 = $5,250
Loss = $5,250 - $5,000 = $250

  Cash                        5,000
  Accumulated Depreciation   15,750
  Loss on Disposal              250
    Machine A                          21,000
```

**b. Machine B Disposal (December 31):**
```
First, record depreciation for current year:
Annual depreciation = ($50,000 - $4,000) / 10 = $4,600

  Depreciation Expense        4,600
    Accumulated Depreciation          4,600

New accumulated depreciation = $36,800 + $4,600 = $41,400
Book value = $50,000 - $41,400 = $8,600
Gain = $10,500 - $8,600 = $1,900

  Cash                        2,500
  Note Receivable             8,000
  Accumulated Depreciation   41,400
    Machine B                          50,000
    Gain on Disposal                    1,900
```

**c. Machine C Disposal (January 1):**
```
Book value = $85,000 - $64,000 = $21,000
Loss = $21,000 (no proceeds)

  Accumulated Depreciation   64,000
  Loss on Disposal           21,000
    Machine C                          85,000
```

**2. Accounting Rationale:**
- Each disposal removes the asset's cost and accumulated depreciation from the books
- Any difference between book value and proceeds is recognized as gain or loss
- Losses are recognized immediately when assets are abandoned or destroyed

## P8-7: Inferring Activities Affecting Fixed Assets from Notes to the Financial Statements

Singapore Airlines reported (in Singapore $ millions):

**Property, Plant, and Equipment:**

| | Beg. Balance | Additions | Disposals | End. Balance |
|---|------------|-----------|-----------|-------------|
| **Cost:** | | | | |
| Aircraft | 19,144.3 | 1,712.4 | 2,108.3 | 18,748.4 |
| Other fixed assets | 4,378.3 | 880.6 | 199.0 | 5,059.9 |
| **Total** | **23,522.6** | **2,593.0** | **2,307.3** | **23,808.3** |

| | Beg. Balance | Depreciation | Impairment | Disposals | End. Balance |
|---|------------|--------------|------------|-----------|-------------|
| **Accumulated Depreciation:** | | | | | |
| Aircraft | 8,598.2 | 1,448.1 | 310.7 | 1,397.0 | 8,960.0 |
| Other fixed assets | 1,826.4 | 127.4 | 27.6 | 159.8 | 1,821.6 |
| **Total** | **10,424.6** | **1,575.5** | **338.3** | **1,556.8** | **10,781.6** |

**Cash Flow Information:**
- Depreciation: $1,589.1 million
- Impairment loss: $338.3 million
- Surplus (gain) on disposal: $(51.2) million

**Required:**

1. Reconstruct the information using T-accounts.
2. Compute the amount of cash received for disposals.
3. Compute the percentage of depreciation expense to cash flows from operations.

**Solution:**

**1. T-Accounts:**

```
Property, Plant, and Equipment
┌─────────────────────────────────────────┐
│ Beg. balance    23,522.6 │ Disposals   2,307.3 │
│ Additions        2,593.0 │                   │
│ ─────────────────────────────────────────── │
│ End. balance    23,808.3 │                   │
└─────────────────────────────────────────┘

Accumulated Depreciation
┌─────────────────────────────────────────┐
│ Disposals      1,556.8 │ Beg. balance 10,424.6 │
│                   │ Depreciation    1,575.5 │
│                   │ Impairment        338.3 │
│ ─────────────────────────────────────────── │
│                   │ End. balance   10,781.6 │
└─────────────────────────────────────────┘
```

**2. Cash Received for Disposals:**
```
Book value of disposals = Cost - Accumulated Depreciation
                        = 2,307.3 - 1,556.8 = 750.5
Gain on disposal = 51.2
Cash received = Book value + Gain = 750.5 + 51.2 = 801.7 million
```

**3. Depreciation to Operating Cash Flow Percentage:**
```
Depreciation / Operating Cash Flow = 1,589.1 / 2,063.5 = 77.0%
```
This high percentage indicates depreciation is a major non-cash adjustment in this capital-intensive industry.

## P8-8: Determining Financial Statement Effects of Activities Related to Various Long-Lived Assets

BSP Company completed these transactions during the current year:

a. January 1: Purchased a patent for $28,000 cash (7-year useful life)
b. January 1: Purchased assets of another business for $164,000 cash, including $10,000 for goodwill
c. December 31: Constructed a storage shed on leased land for $15,600 (lease expires in 3 years)
d. Total ordinary repairs and maintenance: $5,500
e. December 31: Sold Machine A for $6,000 cash (cost $25,000; accumulated depreciation $16,000; 5-year life, $5,000 residual)
f. December 31: Paid $5,000 for complete reconditioning of Machine B (cost $31,000; accumulated depreciation $1,600; 15-year life, $7,000 residual)

**Required:**

1. Indicate the effects on the accounting equation.
2. Compute depreciation and amortization at year-end.

**Solution:**

**1. Accounting Equation Effects:**

| Transaction | Assets | = | Liabilities | + | Stockholders' Equity |
|-------------|--------|---|-------------|---|---------------------|
| a. Patent purchase | +Patent $28,000, -Cash $28,000 | | No effect | | No effect |
| b. Business purchase | +Assets $154,000, +Goodwill $10,000, -Cash $164,000 | | No effect | | No effect |
| c. Shed construction | +Leasehold Improvements $15,600, -Cash $15,600 | | No effect | | No effect |

| Machine B | ($31,000 + $5,000 - $7,000) / 15 | $1,933 |

## P8-9: Computing Goodwill from the Purchase of a Business

Weebok Corporation acquired Sport Shoes, Inc. for $750,000 cash.

**Sport Shoes Balance Sheet (January 5):**

| | Book Value | Market Value |
|---|------------|--------------|
| Accounts receivable (net) | $50,000 | $50,000 |
| Inventory | 385,000 | 350,000 |
| Fixed assets (net) | 156,000 | 208,000 |
| Other assets | 4,000 | 10,000 |
| **Total assets** | **$595,000** | |
| Liabilities | $75,000 | |
| Stockholders' equity | 520,000 | |

**Required:**

1. Compute the amount of goodwill resulting from the purchase.
2. Compute adjustments at year-end for:
   - a. Depreciation of fixed assets (straight-line, 10 years, no residual)
   - b. Goodwill

**Solution:**

**1. Goodwill Calculation:**
```
Fair value of identifiable net assets:
  Accounts receivable      $ 50,000
  Inventory                 350,000
  Fixed assets              208,000
  Other assets               10,000
  Less: Liabilities         (75,000)
  Fair value of net assets $543,000

Goodwill = Purchase price - Fair value of net assets
Goodwill = $750,000 - $543,000 = $207,000
```

**2. Year-End Adjustments:**

**a. Depreciation:**
```
$208,000 / 10 = $20,800

  Depreciation Expense     20,800
    Accumulated Depreciation      20,800
```

**b. Goodwill:** No amortization (indefinite life), but must test for impairment annually.

## P8-10: Computing Amortization, Book Value, and Asset Impairment

Starn Tool Company has five intangible assets:

| Asset | Cost | Date Acquired | Useful Life |
|-------|------|---------------|-------------|
| a. Patent | $55,900 | Jan 1, 2017 | 13 years |
| b. Copyright | $22,500 | Jan 1, 2017 | 10 years |
| c. Franchise | $14,400 | Jan 1, 2017 | 10 years |
| d. License | $14,000 | Jan 1, 2016 | 5 years |
| e. Goodwill | $40,000 | Jan 2014 | Indefinite |

**Required:**

1. Compute amortization for each intangible at December 31, 2017.
2. Give the book value of each at December 31, 2018.
3. On January 2, 2019, the copyright was impaired. Future cash flows: $17,000; Fair value: $16,000. Compute impairment loss.

**Solution:**

**1. Amortization for 2017:**

| Asset | Calculation | 2017 Amortization |
|-------|-------------|-------------------|
| Patent | $55,900 / 13 | $4,300 |
| Copyright | $22,500 / 10 | $2,250 |
| Franchise | $14,400 / 10 | $1,440 |
| License | $14,000 / 5 | $2,800 |
| Goodwill | Indefinite - no amortization | $0 |

**2. Book Value at December 31, 2018:**

| Asset | Cost | Accumulated Amortization | Book Value |
|-------|------|-------------------------|------------|
| Patent | $55,900 | $4,300 × 2 = $8,600 | $47,300 |
| Copyright | $22,500 | $2,250 × 2 = $4,500 | $18,000 |
| Franchise | $14,400 | $1,440 × 2 = $2,880 | $11,520 |
| License | $14,000 | $2,800 × 3 = $8,400 | $5,600 |
| Goodwill | $40,000 | $0 | $40,000 |

**3. Copyright Impairment (January 2, 2019):**
```
Book value = $18,000
Future cash flows = $17,000 (less than book value, so impaired)
Fair value = $16,000
Impairment loss = $18,000 - $16,000 = $2,000
```

## P8-11 (Chapter Supplement): Analyzing and Recording Entries Related to a Change in Estimated Life and Residual Value

Rungano Corporation owns a Didde press:
- Original cost: $400,000
- Original estimated life: 20 years
- Original residual value: $50,000
- Depreciated for 6 years at end of prior year

At beginning of current year: New total estimated life = 25 years, new residual value = $73,000

**Required:**

1. Compute (a) depreciation expense in prior year and (b) book value at end of prior year.
2. Compute depreciation for current year.
3. Give the adjusting entry for current year.

**Solution:**

**1. Prior Year Calculations:**
```
(a) Annual depreciation = ($400,000 - $50,000) / 20 = $17,500

(b) Book value at end of prior year:
    Accumulated depreciation = $17,500 × 6 = $105,000
    Book value = $400,000 - $105,000 = $295,000
```

**2. Current Year Depreciation (Change in Estimate):**
```
Remaining depreciable amount = $295,000 - $73,000 = $222,000
Remaining life = 25 - 6 = 19 years
New annual depreciation = $222,000 / 19 = $11,684
```

**3. Adjusting Entry:**
```
  Depreciation Expense     11,684
    Accumulated Depreciation      11,684
```
